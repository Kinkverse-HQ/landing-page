# Agent contract

Before editing, read [.usl/contracts/workflow.md](.usl/contracts/workflow.md),
[verification](.usl/contracts/verification.md) and [pull requests](.usl/contracts/pull-requests.md).
These define branch, attribution, checkpoint, review and merge requirements.
Current explicit human instructions take precedence; preserve applicable narrower project rules.

Read [project boundaries](.usl/contracts/project.md) before changing behavior.

Load [installed skills](.usl/README.md) only when their trigger applies.
Treat repository instructions as contracts: establish preconditions, perform the required checks,
and report unmet completion conditions. Do not treat missing tooling as a passing check.
